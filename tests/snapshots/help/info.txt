
 Usage: dataio info [OPTIONS] {source}

 Describe a source: format, encoding, delimiter, rows, column types and the first 5 rows.

 Example: dataio info a.csv --json

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    source      <str>  Address of the source, e.g. a.csv or book.xlsx#Sheet1. [required]        │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --format                      <str>               Format name; wins over the extension (see the  │
│                                                   formats command).                              │
│ --sheet                       <str>               Sheet name; wins over the part of the address  │
│                                                   after #.                                       │
│ --table                       <str>               Table name; wins over the part of the address  │
│                                                   after #.                                       │
│ --encoding                    <str>               Text encoding, e.g. utf-8 or cp1251.           │
│ --sep                         <str>               Field delimiter, e.g. ';' or '|'.              │
│ --header      --no-header                         The first row holds the column names.          │
│                                                   [default: header]                              │
│ --as-text     --no-as-text                        Read every value as text.                      │
│                                                   [default: no-as-text]                          │
│ --dtypes                      COLUMN=TYPE         Type of one column as COLUMN=TYPE, e.g.        │
│                                                   freq=int; repeatable.                          │
│ --limit                       <int range> [x>=0]  Read at most this many rows.                   │
│ --json                                            Emit machine-readable JSON output.             │
│ --quiet                                           Suppress non-essential output.                 │
│ --help                                            Show this message and exit.                    │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯


 Usage: dataio restore [OPTIONS] [id]

 Bring a target back from a backup. Not available in this release yet.

 Example: dataio restore --dry-run --json

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│   id      <str>  Backup id from the backups command; the newest when left out.                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --dry-run          Show what would happen without making changes.                                │
│ --confirm          Confirm a destructive action (required together with --non-interactive).      │
│ --json             Emit machine-readable JSON output.                                            │
│ --quiet            Suppress non-essential output.                                                │
│ --help             Show this message and exit.                                                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯

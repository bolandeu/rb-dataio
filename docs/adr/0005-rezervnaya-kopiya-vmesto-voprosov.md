# Резервная копия вместо вопросов при перезаписи

Перед каждой заменой существующих данных dataio сохраняет копию, `restore` возвращает её. Локальные файлы перезаписываются без вопроса: вопрос мешает скриптам и агентам, а копия делает ошибку обратимой. Подтверждение (`--confirm` / `overwrite=True`) остаётся только там, где ошибка особенно дорога: непустой лист Google и запись поверх источника.

Рассмотренные варианты: запрет перезаписи по умолчанию (`mode=error`) — ломает повторные запуски конвейеров.

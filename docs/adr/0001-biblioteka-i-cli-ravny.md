# Библиотека и CLI умеют одно и то же

Каждый параметр `read()` / `write()` / `convert()` — флаг CLI с тем же именем (`as_text` ↔ `--as-text`), логика только в библиотеке. Человек работает из терминала, инструменты — через библиотеку, и оба должны получать одно поведение. Расхождение ловит тест паритета.

Рассмотренные варианты: библиотека главная, CLI тонкий (только `convert IN OUT`) — отвергнуто Человеком в интервью.

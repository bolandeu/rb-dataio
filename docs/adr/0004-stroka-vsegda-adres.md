# Строка без перевода строки — всегда адрес

Однострочная строка в `read()` — это адрес; если такого нет, ошибка `SOURCE_NOT_FOUND` с подсказкой `format="text"`. Угадывание «путь или текст» превратило бы опечатку в имени файла (`phrases.csvv`) в молчаливые данные. Текст — строка с переводом строки, список строк или явный `format="text"`.

The CLI command dataio convert exposes the target columns: --columns takes source column names in the output order, --rename takes old=new pairs. Both accept a comma list and may repeat. A rename value splits on the first '='. Errors from the library keep exit 2 and their message; a malformed --rename value is refused with exit 2 and shows the form old=new. dataio describe and the help of convert show both options. The agent skill (SKILL.md), README and SPEC describe the target columns: the options, the order selection then rename, the refusals with exit 2, split_by and append with them, and the example from semkit.

## Acceptance

- Given in.csv with columns phrase,match,similarity, When dataio convert in.csv out.json --columns phrase,similarity --rename similarity=сходство, Then out.json records have the keys phrase and сходство, in that order. [check: tests/test_cli_target_columns.py]
- Given the same file, When dataio convert in.csv out.csv --columns similarity --columns phrase --rename phrase=p --rename similarity=s, Then the header of out.csv is s,p. [check: tests/test_cli_target_columns.py]
- Given --rename 'a=x,b=y', When convert runs, Then both renames apply; given --rename 'a=b=c', Then column a becomes 'b=c'. [check: tests/test_cli_target_columns.py]
- Given --columns phrase,zz, When dataio convert runs, Then exit code is 2, the error code is INVALID_ARGUMENTS, the message names zz and lists the columns of the table, and out.json is not created; with --json the envelope carries the same error. [check: tests/test_cli_target_columns.py]
- Given --rename similarity (no '='), When dataio convert runs, Then exit code is 2 and the message shows the expected form old=new. [check: tests/test_cli_target_columns.py]
- Given target '-' and --columns phrase, When dataio convert in.csv - runs, Then stdout is plain text of the phrase column only (the single-column rule). [check: tests/test_cli_target_columns.py]
- Given dataio describe and dataio convert --help, When they run, Then both show --columns and --rename with a one-line description; the snapshots are updated. [check: tests/test_cli_target_columns.py]
- Given the bundled SKILL.md, When the test reads it, Then it names --columns and --rename, says selection comes before rename, and says a wrong name or a clash gives INVALID_ARGUMENTS (exit 2). [check: tests/test_describe.py]
- Given README.md and docs/SPEC.md, When a reader opens the writing sections, Then README shows write(df, t, columns=[...], rename={...}) and the semkit CLI example, and SPEC has a Writing user story on target columns and names column choice on read in Out of Scope. [check: tests/test_cli_target_columns.py]
